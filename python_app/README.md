# 🎬 ADgemvid - استوديو إعلانات الفيديو الذكي (AI Smart Video Ad Studio)

تطبيق متكامل مبني بلغة **Python** وبواجهة **Streamlit** متجاوبة 100% مع شاشات الهواتف المحمولة وسطح المكتب، مع دعم أصلي كامل للغة العربية (RTL).

---

## 🚀 المميزات الرئيسية

1. **واجهة مستخدم متجاوبة (Mobile-First UI/UX)**:
   - تصميم حديث ومريح على الجوال بشاشات لمسية وأزرار عريضة.
   - دعم كامل للغة العربية (الاتجاه من اليمين لليسار، خط Cairo الأنيق).
   - حقول إدخال مفتاح Gemini API ونموذج الذكاء الاصطناعي ونبرات التعليق الصوتي العربي.

2. **عقل الذكاء الاصطناعي (Gemini Logic)**:
   - مبني على أحدث مكتبة رسمية: `google-genai` (وليس المكتبات القديمة المهملة).
   - صياغة إعلانية متخصصة باللغة العربية (خطاف جذاب Hook، توضيح القيمة والمزايا، وحث قوي على اتخاذ إجراء CTA).
   - إخراج منظم (Structured Output) يتضمن سكريبت التعليق الصوتي مشكولاً لتفادي أخطاء النطق، وتقطيع المشاهد بالثواني، وكلمات مفتاحية للموسيقى.

3. **محرك الصوتيات والمؤثرات المجاني (Free Media Engine)**:
   - **التعليق الصوتي**: عبر مكتبة `edge-tts` السحابية المجانية فائقة النقاء مع أصوات عربية طبيعية (حامد، سلمى، حمدان، شاكر، زارية، جمال).
   - **الموسيقى الخلفية**: بحث آلي عبر Pixabay API أو استخدام مكتبة المسارات الاحتياطية المجانية المرخصة تجارياً بدون توقف.

4. **المونتاج والتجميع الذكي (Video Assembly & Ducking)**:
   - دمج الفيديو مع التعليق الصوتي والموسيقى عبر `moviepy`.
   - خاصية **Audio Ducking**: خفض صوت موسيقى الخلفية تلقائياً أثناء كلام المعلق الصوتي ورفعها عند فترات الصمت لإبراز الكلمات.
   - مشغل فيديو مدمج وزر تحميل بضغطة واحدة لصيغة MP4 بجودة عالية.

## 🛠️ متطلبات التثبيت (Installation)

تأكد من وجود Python 3.9 أو أحدث، ثم قم بتثبيت الحزم التالية:

```bash
pip install -r requirements.txt
```

أو مباشرة:

```bash
pip install streamlit google-genai edge-tts moviepy requests pydantic python-dotenv
```

> **ملاحظة لـ FFmpeg**: تعتمد مكتبة MoviePy على أداة `ffmpeg`. إذا لم تكن مثبتة على نظامك، يمكنك تثبيتها بسهولة:
> - على أوبونتو/دبيان: `sudo apt update && sudo apt install ffmpeg`
> - على ماك (Homebrew): `brew install ffmpeg`
> - على ويندوز: يمكنك تنزيلها أو استخدام `pip install imageio-ffmpeg`

## 💻 طريقة التشغيل (Run)

1. أنشئ ملف `.env` (اختياري) وضع فيه مفتاح Gemini الخاص بك:
   ```env
   GEMINI_API_KEY="AIzaSy..."
   ```
2. شغّل التطبيق بالأمر:
   ```bash
   streamlit run app.py
   ```
3. سيفتح التطبيق تلقائياً في المتصفح على العنوان `http://localhost:8501`.
